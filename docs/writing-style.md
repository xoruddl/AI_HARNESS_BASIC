# 문체

## md 문서

- 개조식. 한 줄에 규칙 하나.
- 배경, 사연, 도입부, 맺음말 쓰지 않는다. 규칙만 쓴다.
- 문장은 "~한다", "~하지 않는다" 로 끝낸다.
- 설명이 길어지면 표·예시 코드로 바꾼다.
- 문서 하나 150줄 이내. 넘으면 나눈다. (코드 예시 모음 문서는 제외)
- 같은 내용을 여러 문서에 반복하지 않는다. 링크한다.

```
좋음
- 커밋 1개 후 멈춘다.

나쁨
- 효율적인 협업과 원활한 피드백 루프를 위해, 에이전트는 각 커밋이 완료될 때마다
  작업을 일시 중지하고 사용자의 의견을 기다리는 것이 바람직합니다.
```

## 커밋·PR·리뷰 답글

사람이 쓴 것처럼 쓴다.

- 짧게. 사실만.
- 한 일만 쓴다. 기대 효과, 소감 쓰지 않는다.
- 불릿은 3개 이내.

금지 표현:

| 종류 | 예 |
| --- | --- |
| 서사형 도입 | "이번 PR에서는 ~", "~을 통해 ~을 구현하였습니다" |
| 과장 수식어 | 강력한, 견고한, 원활한, 효율적인, 종합적인, 체계적인, 향상 |
| 정리 문구 | "요약하면", "결론적으로", "전반적으로" |
| 장식 | 이모지, 헤더마다 아이콘, 과도한 볼드 |
| AI 서명 | `Co-Authored-By: Claude`, `Generated with Claude Code`, 🤖 |
